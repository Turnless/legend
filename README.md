# LEGEND ($LGD) — Website & Brand Assets

A responsive, light-theme concept website for LEGEND ($LGD), with an original crowned internet-meme character direction and a meme gallery.

## Preview locally

1. Extract the ZIP.
2. Open `legend_lgd_package/index.html` in a modern browser.
3. Keep the `assets/` folder beside `index.html`, `styles.css`, and `script.js`.

No build step or backend is required. Google Fonts are loaded remotely; system fallbacks are included.

## Website features

- Expanded mission, character story, creative principles, manifesto, community, token details, and FAQ sections.
- Responsive mobile navigation.
- Scroll reveal transitions and reduced-motion support.
- Interactive meme gallery with image viewer, previous/next controls, keyboard navigation, and Escape-to-close.
- Copy button for Robinhood Chain's chain ID.
- Light palette: white, cream, green, sky blue, and restrained gold. No dark mode or purple.
- Robinhood Chain mainnet information shown from official documentation: chain ID 4663, ETH gas token, and official block explorer.

## Important before launch

- The token contract address has not been provided. The website deliberately does not invent one or link to a buy page.
- Add official social links only after confirming the accounts.
- The site makes no claim of affiliation, endorsement, sponsorship, or listing by Robinhood.
- Meme images and PFP/header images in this package are concept assets. Review and replace them with final standalone exports before public launch.
- This is a static website. Hosting/deployment is a separate step.

## Main files

- `index.html` — page structure and copy
- `styles.css` — layout, responsive styling, motion and interaction states
- `script.js` — meme viewer, mobile navigation, copy interaction, and reveal animations
- `assets/brand/` — PFP/header concept images and reference
- `assets/memes/` — 20 individual meme concept images
